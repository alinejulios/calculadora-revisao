# Calculadora de Revisão Acadêmica

Calculadora de orçamento para serviços de revisão acadêmica, com precificação por lauda conforme padrão ABNT.

- Revisão em língua estrangeira, formatação ABNT e revisão ortográfica/gramatical
- Combo ABNT + Revisão com desconto
- Adicional de urgência (+20%)
- Exportação do orçamento em PNG, PDF ou texto

Página estática (HTML único) — publicada na Vercel.
